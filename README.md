# Quick News

Quick News is an application that delivers personalized news content based on user preferences and location.

Quick News allows users to browse, read, and save news articles through a clean and intuitive interface. The application integrates with a third-party news API while managing user accounts, authentication, and preferences on the backend.

---

## Key Features

- Secure user authentication and login
- Location-based and filtered news feeds
- Real-time news updates
- User profiles with saved articles

---
